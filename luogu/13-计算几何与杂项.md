# 阶段 13：计算几何与杂项

> 对应 ICPC 计划「阶段四」暑期集训。区域赛里几何题常常是「会模板就能拿分」，性价比高。

## A. 向量与叉积基础

- [ ] [P1355 神秘大三角](https://www.luogu.com.cn/problem/P1355) `L3`：叉积判点在三角形内。
- [ ] [P2312 解方程](https://www.luogu.com.cn/problem/P2312) `L4`：秦九韶 + 取模哈希（不算几何，但常一起考）。
- [ ] [P2181 对角线](https://www.luogu.com.cn/problem/P2181) `L3`：组合几何，与 `08-数学与数论.md` 重复出现，做一次即可。

## B. 凸包与最近点对

- [ ] [P2742 圈奶牛](https://www.luogu.com.cn/problem/P2742) `L4`：Andrew 凸包模板，注意共线点处理。
- [ ] [P1257 平面上的最接近点对](https://www.luogu.com.cn/problem/P1257) `L3`：分治入门版。
- [ ] [P1429 平面最近点对（加强版）](https://www.luogu.com.cn/problem/P1429) `L4`：分治 + 按 y 排序。
- [ ] [P1452 Beauty Contest](https://www.luogu.com.cn/problem/P1452) `L5`：旋转卡壳求直径。
- [ ] [P4557 战争](https://www.luogu.com.cn/problem/P4557) `L5`：Minkowski 和 + 凸包（选学）。

## 过关标准

- 叉积、点积的几何意义与符号判断能画图说明。
- 凸包模板能默写，并知道为什么要先按极角/坐标排序。
- 浮点比较统一用 `eps`，能说出为什么不能直接 `==`。

## 杂项清单（不成题单，见到就补）

- [ ] 高精度：加减乘、压位。
- [ ] 离散化：排序 + `unique` + `lower_bound`。
- [ ] 随机化：`mt19937`、随机化哈希、爬山。
- [ ] 对拍脚本：`gen.cpp` / `brute.cpp` / `std.cpp` 三件套。
- [ ] 快读快写：`getchar` 版与 `ios::sync_with_stdio(false)`。
