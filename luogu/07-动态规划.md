# 阶段 7：动态规划

> 对应 ICPC 计划「阶段二」。这是你目前**完全空白**的最大模块，优先级最高。
> 顺序：线性 → 背包 → 区间 → 树形/记忆化 → 状压/数位。不要跳。

## 过关标准

- 能对任意一题说出：状态是什么、转移方程、枚举顺序、边界。
- 能判断「这题为什么不能用贪心」（举反例）。
- 背包三类能默写并解释枚举顺序的正倒。
- 树形 DP 能写出 `dfs(u)` 返回 `dp[u][0/1]` 的骨架。
