# 阶段 14：线上赛与复盘法

> 题单解决「会」，比赛解决「会做」。每周至少打一场线上赛，这是提升最快的环节。

## A. 每周节奏（对应 `../ICPC 学习计划.md`）

| 时间 | 内容 | 时长 |
|---|---|---:|
| 工作日 ×5 | 1 道题（想 15 / 写 25 / 复盘 10） | 45-60 min |
| 周六 | 虚拟赛（CF Div.3/Div.4 或 AtCoder ABC） | 2-3 h |
| 周日 | 补题：把比赛没做出来的题搞懂 | 1-2 h |
| 每 4 周 | 洛谷月赛或 CF Div.2 全场 | 3 h |

## B. 比赛平台

| 平台 | 比赛 | 建议 |
|---|---|---|
| [Codeforces](https://codeforces.com) | Div.4 / Div.3（每周） | 阶段一主战场，目标 A-C 稳过 |
| [Codeforces](https://codeforces.com) | Div.2（每 1-2 周） | 阶段二起，目标 A-C |
| [AtCoder](https://atcoder.jp) | ABC（每周六 20:00） | A-D 题，题目短、适合练速度 |
| [洛谷](https://www.luogu.com.cn/contest) | 洛谷月赛 / 普及组模拟赛 | 中文题面，难度参考价值高 |
| [NowCoder](https://ac.nowcoder.com) | 牛客练习赛 | 中文，题目偏竞赛向 |

## C. 复盘模板（每题必写，3 行就够）

```text
题号 / 比赛场次：
结果：独立通过 / 看提示 / 看题解 / 没做出来
核心模型：（一句话，例如「二分答案 + 贪心检查」）
复杂度：时间 / 空间
错因：边界 / 下标 / 溢出 / 算法选错 / 实现细节
下次注意：（一条具体可执行的规则）
```

## D. 选题难度匹配（重要，避免浪费时间）

- 一场比赛里，**能稳定做出来的 + 想 20 分钟能做出来的**，占 60%-70% 最合适。
- 目标难度：当前 Rating + 100~200 分的题。
- 连续 3 题都能秒杀 → 难度太低，换更难的。
- 1 小时零进展 → 难度太高，降一档。

| 当前水平 | 建议题目 |
|---|---|
| Rating < 1000 | CF Div.4 A-B、洛谷 `L1` |
| Rating 1000-1200 | CF Div.3 A-C、洛谷 `L2` |
| Rating 1200-1400 | CF Div.3 D、Div.2 A-B、洛谷 `L3` |
| Rating 1400+ | CF Div.2 C、洛谷 `L4` |

## E. 错题本

在仓库新建 `notes/错题本.md`，每题只记 3 行：

```text
[日期] 题号 一句话模型
错因：
下次规则：
```

**只记「下次规则」，不抄题解。** 抄题解等于没做。

## 过关标准

- 能在一场 2 小时虚拟赛里稳定 AC 至少 3 题。
- 赛后补题率 ≥ 80%（没做出来的题都复盘过）。
- 错题本能翻出至少 10 条「下次规则」。
