## 标记说明

## 推荐刷题顺序

1. **二叉树**：先吃透三种遍历的递归写法，再扩展到深度、翻转、对称、路径等问题。
2. **图**：从网格 DFS/BFS 入手，再学并查集、拓扑排序、最短路与最小生成树。
3. **堆**：先掌握 `priority_queue` 基础用法，再用堆解决 Top-K、频率排序与多路归并。

建议每道题先独立写出可运行代码，再对照已有实现复盘时间复杂度与边界处理。

## 进度记录

每完成一题，把对应路线图中的 `[ ]` 改为 `[x]`，并可在题解文件顶部补充思路、复杂度和易错点。
