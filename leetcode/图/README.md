## 复盘要点

- 邻接表 vs 邻接矩阵的取舍要结合数据范围。
- Dijkstra 用 `priority_queue` 时注意“过期节点跳过”（`if (d > dist[u]) continue;`）。
- Kruskal 前先按边权排序，并用并查集判环。
- 拓扑排序入度为 0 入队，最终计数等于节点数才无环。
