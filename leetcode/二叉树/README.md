## 复盘要点

- 递归出口（`nullptr` / 叶子）与返回值要成对设计。
- 深度、路径类问题注意“参数传递”还是“返回值累加”。
- 验证 BST 不能只比较父子节点，要用全局上下界或中序遍历。
