## 复盘要点

- 求第 K 大用**小顶堆**，求第 K 小用**大顶堆**，方向别弄反。
- C++ 默认 `priority_queue` 是大顶堆；小顶堆需 `greater<T>`。
- Top-K 保持堆大小为 K，超出即 `pop`，整体 O(n log K)。
- 对顶堆维护中位数：大顶堆放小半，小顶堆放大半，保持两者数量差不超过 1。
